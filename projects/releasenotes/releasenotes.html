Release Notes Examples

This page showcases a variety of release notes I've written. I chose these examples to show different audiences, levels of technicality, and methods of presenting the information.

The samples are from two different software platforms:

  • CXone: Contact center software
  • Video Banking/Unified Platform: Fintech software for financial institutions

Keep in mind that these notes are written for audiences who use the software. Therefore, the notes assume that readers understand certain concepts or jargon unique to the software.

CXone

The primary audience for CXone release notes was system administrators. Developers may have also checked the notes for API or scripting changes, which were specifically labeled sections. The following were key styles and approaches to these notes:

  • The notes were more than a changelog list. Instead, they were one paragraph (on average) with key details of the change.
  • A typical format was to explain the before and after functionality, following this format: "Previously, {it worked this way}. In this release, {it now works this way}".
  • The notes linked to correlating online help documentation about the change.
  • Each note had a table indicating quick information, like whether the UI was impacted by the change.

Remove the Marketing Panel from the Login Page

Currently, the CXone Mpower login page is split in half. One side is the login form where users enter their credentials. The other side is the marketing panel where NiCE displays promotional content. In this release, you can enable or disable the marketing panel from the Account Settings page.

Configure After Contact Work at an Agent Level

You will be able to configure after contact work (ACW) settings for individual agents via API. This is a set amount of time at the end of an interaction, allowing the agent time to complete tasks like entering notes.

Several agent APIs will include the following new fields:

  • Additional ACW Time Enabled: Indicates if ACW time is enabled for the agent (Boolean).
  • Additional ACW Duration: Specifies the duration of additional ACW time (integer, 1–7,200 seconds).

The following APIs will be updated to version 34 and support these new fields:

  • PUT /agents/{agentId}
  • GET /agents
  • GET /agents/{agentId}
  • POST /agents
  • PUT /agents

Fabric Connect for Voice Calls

Fabric Connect lets you use the Equinix Fabric for voice traffic. This routes your voice calls over a secure, global, high-performance network instead of the public internet. The Fabric provides high reliability, lower latency, and advanced security. Additionally, it’s an affordable option and quick to set up, even for enterprise organizations.

Setup requires you to establish a connection with the Equinix Fabric. After doing so, you can choose bandwidth options between 50 Mbps-10 Gbps. To improve the performance of your voice calls with Fabric Connect, reach out to your Account Representative.

Video Banking/Unified Platform

The primary audience for the Unified Platform release notes was system administrators. The following were key styles and approaches to these notes:

  • The notes linked to correlating support site documentation. I removed links from these notes since the support site is not publicly accessible.
  • Each note had a value statement indicated with the light bulb 💡.
  • Each note also listed at-a-glance information, like whether it was for a paid feature or if the change impacted the UI.

Symitar: Handling Unknown First and Last Names

💡 Import more accurate contact data from Symitar

During the current sync process with Symitar, if a contact’s name is empty, the system pulls in the contact’s phone number instead. With the November release, if the Symitar sync file does not contain a contact’s first or last name, it enters FNU (first name unknown) or LNU (last name unknown).

Availability: On deploy
Customer Requested: Yes
UI Change: No
Feature Type: Premium

ID Verification Log Report Enhancements

💡 Access in-depth data on failed ID scans

Last release, the ID Verification Log report was added for Video Verify users. This report helps you gain insight into why ID scans may have failed. With this release, the following columns were added to the report:
