Release Notes Examples

This page showcases a variety of release notes I've written. I chose these examples to show different audiences, levels of technicality, and methods of presenting the information.

The samples are from two different software platforms:

  • CXone: Call center software
  • Video Banking/Unified Platform: Fintech software

Keep in mind that these notes are written for audiences who use the software. Therefore, the notes assume that readers understand certain concepts or terms.

CXone Examples

The primary audience was system administrators. Developers may have also checked the notes for API or scripting changes, so some were written for both admins and devs. The following were key styles and approaches to the CXone release notes:

  • They were more than a changelog list. Instead, they were one paragraph (on average) with key details of the change.
  • A typical format was to explain the before and after functionality, like this: "Previously, {it worked this way}. In this release, {it now works this way}".
  • The target reading level was below 10th grade.
  • The notes linked to online help documentation that was added or updated for the change.
  • Each note had a table indicating at-a-glance information, like whether the UI was impacted.

Remove the Marketing Panel from the Login Page

Currently, the CXone Mpower login page is split in half. One side is the login form where users enter their credentials. The other side is the marketing panel where NiCE displays promotional content. In this release, you can enable or disable the marketing panel from the Account Settings page.

Configure After Contact Work at an Agent Level

You can now configure after contact work (ACW) settings for individual agents via API. This is a set amount of time at the end of an interaction, allowing the agent time to complete tasks like entering notes.

Several agent APIs now have the following new fields:

  • Additional ACW Time Enabled: Indicates if ACW time is enabled for the agent (Boolean).
  • Additional ACW Duration: Specifies the duration of additional ACW time (integer, 1–7,200 seconds).

The following APIs were updated to version 34 and support these new fields:

  • PUT /agents/{agentId}
  • GET /agents
  • GET /agents/{agentId}
  • POST /agents
  • PUT /agents

Fabric Connect for Voice Calls

Fabric Connect lets you use the Equinix Fabric for voice traffic. This routes your voice calls over a secure, global, high-performance network instead of the public internet. The Fabric provides high reliability, lower latency, and advanced security. Additionally, it’s an affordable option and quick to set up, even for enterprise organizations.

Setup requires you to establish a connection with the Equinix Fabric. After doing so, you can choose bandwidth options between 50 Mbps-10 Gbps. To improve the performance of your voice calls with Fabric Connect, reach out to your Account Representative.

Video Banking/Unified Platform Examples

The primary audience was system administrators. The following were key styles and approaches to these notes:

  • The notes linked to correlating support site documentation. I removed links from these notes since the support site is not publicly accessible.
  • Each note had a value statement or marketing blurb, indicated by the light bulb 💡.
  • The target reading level was below 10th grade.
  • Each note listed at-a-glance information, like whether the UI was impacted or if it was a paid feature.

Symitar: Handling Unknown First and Last Names

💡 Import more accurate contact data from Symitar

Historically, if a contact in Symitar did not have a name, the sync file entered their phone number as the first name.

With this release, the system now enters FNU (first name unknown) or LNU (last name unknown) instead of the phone number. This cleans up your contact list in the Unified Platform. It also prevents agents from misinterpreting contact entries.

Availability: On deploy
Customer Requested: Yes
UI Change: No
